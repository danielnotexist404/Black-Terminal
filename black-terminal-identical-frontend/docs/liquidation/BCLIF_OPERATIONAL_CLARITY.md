# BCLIF Operational Clarity

## Chapter III-C6 operator defaults

The default `Reference` preset is visual-first but truth-preserving: it shows the calibrated V2 scalar field with no open dashboards, labels, event nodes, provenance panels, or raw diagnostics. `Verified` raises evidence emphasis, and `Research` exposes wider diagnostic context. `Raw Exposure` and `Validity` are explicit audit views, never default market views. Renderer selection, visual mode, theme, opacity, purple floor, gamma, robust quantiles, normalization, and high-DPI LOD are persisted presentation settings.

The permanent compact badge reports authority and collection state without covering the plot. Browser fallback remains visibly labeled as estimated context. Yellow is visually rare and remains gated by evidence metadata; a bright pixel is not a promise of liquidation or account inventory.

Chapter III-C2 changes presentation and operator workflow without rewriting the causal cohort engine. The full modeled liquidation field remains available, while the default `Trade Focus` preset projects only the chart's operational price domain. Distant modeled cohorts therefore no longer compress candles by default.

## Operator views

- `Trade Focus` — default chart-scale projection, subdued historical context, selective thermal extremes, high candle contrast, four labels maximum.
- `High Confidence` — 75% confidence floor, maximum candle contrast, live authority emphasized.
- `Live Calibrated` — shows the live-calibrated channel and its real collection-start boundary.
- `Full Spectrum Research` — exposes the complete retained model price range without changing model state.
- `Raw Model` — global normalization, no confidence weighting, full context, diagnostics on.

Price display is independent of presets and supports Chart Scale, current price ±5/10/20/40%, Auto Focus, Full Model Range, and Custom. Chart Scale is the default.

The compact dashboard is collapsible and draggable. It reports the nearest qualifying shelves above and below mark, pressure balance, authority, and event-history coverage. Default labels are selected deterministically and capped at four. The always-visible badge distinguishes persistent, browser, replay, and test authority even when diagnostics are hidden.

Cluster rows and chart labels expose the evidence class in their native tooltip, so an operator can distinguish OI-only context from trade-, liquidation-, book-, or fully supported shelves without opening developer diagnostics. Heatmap opacity is constrained to 10–100%; Trade Focus defaults to 45%. Candles remain at least 95% opaque while BCLIF is active, with `High` contrast by default and `Maximum` in the High Confidence preset.

For a three-week view, browser/test contexts say `3W OI CONTEXT · LIVE EVENTS COLLECTING`. Only a persistent snapshot with at least 99.5% event coverage says `3W FULL EVENT HISTORY`.

## Seam and boundary audit

| Boundary | Rendering contract |
|---|---|
| Real source start | The first live-calibrated column is derived from measured source coverage and receives the optional `REAL SOURCE START` marker. Earlier browser-session history remains low-authority context. |
| Real data gap | Invalid columns are retained and hatched; they are never painted as low purple exposure or interpolated through. |
| Model version | MODEL identity includes the model version. A new version produces a new snapshot/identity; no cross-version field blend is permitted. |
| Tile stitch | Verified tile columns share the explicit time/price lattice. Rendering uses one projected atlas and does not apply a blur across invalid seams. |
| Normalization | Global, visible-focus, hybrid, fixed-absolute, OI-relative, and confidence-weighted modes are explicit display choices. They do not mutate cohort state. |
| Raster replacement | The worker keeps the last complete texture until the generation-keyed replacement is ready. Pixi teardown preserves shared global resources, preventing the prior remount/black-canvas defect. |

DISPLAY RASTER identity includes exposure bytes, evidence authority and coverage, confidence and confirmed-event channels, display settings, camera domain, grid, and current-price lattice. MODEL and EXPOSURE identities stay unchanged when presentation settings change.

State A remains unchanged: repository complete; persistent host not provided; collector not deployed; migrations not applied; browser fallback active.
## Chapter III-C5 cold-start behavior

Renderer schema V7 separates context visibility (25%), labels (60%) and high-authority color (75%). Strict filtering is off by default and produces an explicit FILTERED_EMPTY HUD state when enabled. The replaying snapshot store makes model-first and renderer-first mount orders equivalent. One compact overlay badge replaces open diagnostics and cluster panels by default.
