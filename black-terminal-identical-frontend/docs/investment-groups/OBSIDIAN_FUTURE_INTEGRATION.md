# Obsidian future integration

Obsidian Vault is a research preview, not an operating investment method. The current UI offers a research summary and waitlist. The database comment and API result explicitly state that entries do not represent deposits, shares, balances, lock periods or redemption rights.

The implementation does not deploy a contract, generate a vault/deposit address, accept or lock capital, sign an investment contract, report vault TVL, combine Obsidian interest with Copy Trading capital, imply an audit/custody approval, or promise instant redemption.

Future activation is blocked on a separate protocol/security chapter, audited contracts, accounting and settlement design, legal/product approval, supported lock/redemption semantics, custody threat modeling, independent certification and an explicit production migration. Copy Trading's immediate pause/leave semantics must not be reused as a promise about a future on-chain vault.
