# Strategy Target Matrix UX

Paper is a separate default target. Bybit Demo targets use ten stable display slots.

An empty slot is a compact placeholder and has no database row, subscription, snapshot request or cockpit. An occupied slot becomes a compact tile; detailed state is loaded only for an occupied selection. Disconnecting returns the slot to empty while audit and historical records remain retained.

New Bybit Demo targets pass ownership, credential, private-stream and reconciliation checks. An explicit non-zero risk policy is required before arming. The demo execution worker is isolated from real-funds Mainnet credentials, and one Demo account can have only one armed strategy until multi-strategy venue-position attribution is certified.
