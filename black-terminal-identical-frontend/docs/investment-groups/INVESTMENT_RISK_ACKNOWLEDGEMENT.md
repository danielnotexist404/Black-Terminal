# Investment risk acknowledgement

Current version: `2026-08-12.v1`.

The active document is server-managed in `group_risk_disclosure_documents`. Acceptance requires the document end to be reached, every mandatory statement to be checked, and an explicit continue action. The record stores user, group, disclosure version/hash, locale, acknowledgement snapshot, application version and timestamp. It excludes device fingerprints and secrets.

Material wording changes publish a new active version. New entries require an acceptance whose version and hash match that document. The disclosure covers lack of profit guarantees, potential total capital loss, leverage/liquidation, execution divergence, persistent server execution, absence of withdrawal authority and the member's unconditional pause/leave right.

The supplied text is product implementation copy, not a substitute for qualified legal review before broad public launch.
