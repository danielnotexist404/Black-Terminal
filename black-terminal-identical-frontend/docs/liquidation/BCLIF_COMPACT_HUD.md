# BCLIF compact operational HUD

The default BCLIF interface is one overlay-only details badge. Its closed target is at most 280×64 px and it does not reserve layout space, move the price axis or change chart/model hashes.

Closed content is limited to BCLIF state, authority, OI/events coverage and confidence. Expanding it reveals the reason, raw/visible/upload counts, model/render generations, lag and actions. Filtered state offers Show OI Context and Open Settings.

Full hashes, grid diagnostics, provenance and the legacy operational cluster dashboard remain user-enabled tools and default to hidden/collapsed under schema V7. Unsupported venues clear stale shelves and show one compact unavailable badge.
