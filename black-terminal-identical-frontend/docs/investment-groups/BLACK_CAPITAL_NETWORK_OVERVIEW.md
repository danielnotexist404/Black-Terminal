# Black Capital Network overview

Phase V Chapter IV turns Investment Groups into a server-backed capital network while preserving independent member accounts.

The operating path is: discover group -> versioned risk acceptance -> select Copy Trading -> configure a withdrawal-prohibited mandate -> optional manager approval -> Black Cloud activation -> signed group intent -> OMS/EMS risk evaluation -> independent follower plan -> member broker account.

Copy Trading and Obsidian are intentionally distinct. Copy Trading is revocable execution against a member-owned account. A member can pause or leave at any time and future-entry authority is revoked immediately. Obsidian is a future research protocol; the current product accepts only waitlist interest and does not accept deposits, create addresses, report balances or promise redemption.

Canonical sources are Supabase membership/mandate records, Black Cloud account state, PositionManager group attribution and coarse aggregate snapshots. The browser is an authorized view/control surface, never an execution fan-out engine.
