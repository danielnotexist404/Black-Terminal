# Strategy Target Matrix UX

Paper is a separate default target. Live targets use ten stable display slots.

An empty slot is a compact placeholder and has no database row, subscription, snapshot request or cockpit. An occupied slot becomes a compact tile; detailed state is loaded only for an occupied selection. Disconnecting returns the slot to empty while audit and historical records remain retained.

New broker or Investment Group targets pass ownership and readiness validation and are created from the existing server route. Default live policy remains 0% allocation, 0% per-trade amount and not armed. Preview displays `LIVE EXECUTION NOT CERTIFIED`; the chapter cannot activate or fan out real trading.
