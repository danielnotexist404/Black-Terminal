# BC-RDA Black Core renderer

The Pixi renderer uses the shared oscillator camera and batches the zero line, P50–P99 distribution fan, sigma lines, raw/smoothed wave, optional worsening-velocity wave, risk strip, current marker, episode trough/recovery markers, compact dashboard, optional expanded metric table, and historical DDA crosshair tooltip. It creates no per-bar DOM nodes.

Dynamic Tail is default. Fixed 10/20/50 and custom depth scales are available. The Black Terminal palette uses near-black, silver/white, dark blood red, crimson, and a restrained bright-red extreme. Compatibility themes map all eight source palettes (Gold, EdgeTools, Behavioral, Quant, Ocean, Fire, Matrix, Arctic). Native Black Terminal Blood, Institutional Monochrome, and custom palettes are separate. Dashboard position controls all four corners. Rendering settings do not enter numerical hashes.
